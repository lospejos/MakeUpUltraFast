# Свечение руд: добавление руд из других модов

Свечение руд заставляет цветные пиксели рудных блоков (алмазы, золото, редстоун и т. д.) светиться в темноте. Камень вокруг не светится.

Руды из модов по умолчанию не светятся. Шейдерпак считает блок рудой, только если его ID указан в `shaders/block.properties`. Менять сами моды не нужно.

## Как добавить руду из мода

1. Узнайте ID блока в игре: нажмите `F3` и наведите прицел на блок. ID показан как `modid:block_name`, например `examplemod:ruby_ore`.
2. Откройте `shaders/block.properties`.
3. Найдите строку, которая начинается с `block.10091 =`. Она находится под комментарием `# ORES`.
4. Допишите ID блока в конец этой строки через пробел:

   ```
   block.10091 = coal_ore iron_ore ... examplemod:ruby_ore examplemod:deepslate_ruby_ore
   ```
5. Сохраните файл и перезагрузите шейдеры в игре (`R` в окне шейдеров или повторно выберите пак).

## Правила

- Блоки из модов пишутся с неймспейсом: `modid:name`. Без неймспейса можно писать только ванильные блоки.
- В `block.properties` две секции, разделённые `#if MC_VERSION >= 11300` / `#else`. Первая для Minecraft 1.13 и новее, вторая для 1.12 и старее. Правьте ту секцию, которая подходит вашей версии Minecraft. В секции для 1.12 блоки с вариантами пишутся как `modid:block:variant=value`.
- Состояния блока можно указать как `modid:block:property=value`.
- Маски вроде `*_ore` не поддерживаются. Каждый блок нужно указать полным ID.
- Каждый ID должен быть только в одной строке `block.XXXXX`. Если блок уже есть в другой группе (например, в группе металлов `block.10400`), сначала удалите его оттуда.

## Настройка

- `ORE_GLOW` в `shaders/lib/config.glsl` задаёт силу свечения. `0.0` выключает его. Значение по умолчанию: `0.8`.
- Светятся только пиксели с достаточной насыщенностью цвета. Если текстура руды из мода в основном серая, свечение будет слабым. Чтобы светилось больше пикселей, уменьшите порог в `smoothstep(0.12, 0.25, ...)` в `shaders/common/solid_blocks_fragment.glsl`.

## Ограничения

- Руды на дальней местности Voxy и Distant Horizons не светятся.
- В игровом меню шейдерпака пока нет пункта для свечения руд.
